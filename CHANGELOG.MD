# Changelog

Все значимые изменения в этом проекте будут документироваться здесь.


## [0.1.0] - 2026-07-24

### 🚀 Добавлено

- Инициализация проекта: базовая игра «Сапер» для веб-формата
- Игровое поле 9×9 с 10 минами (стандартный режим «новичок»)
- Левый клик — открытие клетки
- Правый клик — установка/снятие флага
- Первый клик всегда безопасен (мины генерируются после первого хода)
- Автоматическое раскрытие пустых клеток (DFS)
- Счётчик оставшихся мин
- Таймер (запускается с первого клика)
- Кнопка смайлика для перезапуска игры
- Базовый визуальный стиль (рельефные клетки, имитация объёма)

### 🛠️ Изменено

- Монолитный `index.html` разбит на отдельные файлы для лучшей поддержки кода:
  - `index.html` — структура
  - `style.css` — стили
  - `script.js` — игровая логика

### 📦 Техническое

- Проект инициализирован с Git
- Создан репозиторий на GitHub
- Добавлен README.md с описанием базовой версии
- Добавлен CHANGELOG.md для отслеживания обновлений
