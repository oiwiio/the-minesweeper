# Сапер · Базовая версия

Это **минималистичная реализация** классического «Сапера» для веб-формата.  
Проект создан как **стартовая точка** — чистый, понятный код без лишних украшений, чтобы вы могли легко добавлять свои фичи и экспериментировать.

## 🎯 Что внутри

- Игровое поле **9×9** с **10 минами** (стандартный «новичок»)
- Левый клик — открыть клетку, правый — поставить/убрать флаг
- Первый клик всегда безопасен (мины генерируются после)
- Автоматическое открытие пустых клеток
- Счётчик мин и таймер
- Кнопка смайлика для перезапуска игры

## 🧠 Для чего это

Эта версия — **каркас**, на который вы можете навешивать «мясо»:

- Новые размеры поля и количество мин
- Режимы сложности (лёгкий, средний, экспертный)
- Кастомизация внешнего вида (темы, анимации)
- Звуковые эффекты
- Рекорды и статистика
- Мультиплеер или режим «на время»
- И всё, что подскажет фантазия!

## 🚀 Как запустить

Просто откройте файл `index.html` в любом современном браузере.  
Всё работает без сервера, зависимостей и сборщиков.

## 📁 Структура

Проект состоит из одного HTML-файла, в котором объединены:

- HTML-разметка
- Все стили (CSS)
- Вся логика (JavaScript)

**Лицензия:** можно использовать как угодно. Сделано для обучения и творчества 🧨
