# 💣 Сапёр · Neon Edition

Классический «Сапёр» в тёмной неоновой обёртке — с адаптивным управлением под телефон, несколькими размерами поля и капелькой драмы при проигрыше.

**[▶ Играть онлайн](https://oiwiio.github.io/the-minesweeper/)**

---

## 🎮 Что внутри

- 🕹 **Три размера поля** — 9×9, 12×12 и 24×24, с автоматически подобранной плотностью мин
- 📱 **Мобильный режим** — панель «Открыть / Флаг» рядом с полем, чтобы не зажимать клетку пальцем
- 🖱 **Десктоп как обычно** — левый клик открывает, правый — ставит флаг, независимо от выбранного режима
- 🛡 **Безопасный первый клик** — мины расставляются только после него, попасть на мину сразу невозможно
- 🌊 **Автооткрытие пустых зон** — классический разлив по нулевым клеткам
- 🚩 **Честная разметка после проигрыша** — верно поставленные флаги остаются флагом, неверные — помечаются крестиком
- 😮 **Живой смайлик** — реагирует на зажатие клетки, меняется на 😵 при проигрыше и 😎 при победе
- 🔴 **Красное свечение при проигрыше** — пульсирует по всей странице, полю и рамке контейнера разом
- 📐 **Резиновая вёрстка** — размер клетки пересчитывается под ширину экрана, поле не вылезает за пределы телефона

## 🕹 Управление

| Действие              | Десктоп          | Телефон                    |
|-----------------------|------------------|----------------------------|
| Открыть клетку        | Левый клик       | Тап в режиме **⛏ Открыть** |
| Поставить/снять флаг  | Правый клик      | Тап в режиме **⚑ Флаг**    |
| Новая игра            | Клик по смайлику | Тап по смайлику            |

## 📐 Сложность

| Поле   | Мин | Плотность |
|--------|-----|-----------|
| 9×9    | 10  | ~12%      |

## 🚀 Как запустить

Открой `index.html` в любом современном браузере — без сервера, зависимостей и сборки.

Либо сразу играй по ссылке: **https://oiwiio.github.io/the-minesweeper/**

## 📁 Структура проекта

```
├── index.html   — разметка
├── style.css    — вся визуальная часть (тёмная неоновая тема)
└── script.js    — вся логика игры
```

Код специально держится в трёх читаемых файлах без сборщиков и фреймворков — легко залезть и подкрутить под себя.
